# HDK.io

**Engineering systems that scale.**

HDK.io is an engineering-first technology organization focused on designing, building, and explaining reliable, scalable software systems.

[Website](https://hdk.io.vn) · [GitHub](https://github.com/hdk-io)

---

## Engineering

We work across the layers that make modern software systems reliable in production:

- **Software Architecture** — boundaries, contracts, trade-offs, and system evolution
- **Distributed Systems** — consistency, coordination, messaging, failure modes, and resilience
- **Cloud Engineering** — infrastructure, containers, Kubernetes, deployment, and operations
- **Backend Engineering** — APIs, concurrency, reactive systems, performance, and runtime behavior
- **Data & Databases** — storage models, indexing, caching, transactions, and data distribution
- **Reliability & Performance** — observability, scalability, capacity, latency, and fault tolerance

## Principles

```text
Understand the system.
Make trade-offs explicit.
Design for failure.
Measure before optimizing.

```
